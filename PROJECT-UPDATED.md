# MasteryOS Updated Product Charter

This temporary review copy captures the expanded product concept before the canonical PROJECT.md is replaced after its current SHA is fetched again.

MasteryOS is a personal, local-first technology mastery environment spanning software engineering, computer science, AI, programming, systems, data, cybersecurity, cloud, developer tooling, mathematics for computing, and related technical disciplines.

The system has a universal core, then program-specific routes, then advanced/specialist/frontier depth. It should reach at least university-equivalent depth in core areas and deliberately include valuable uncommon topics that are rarely packaged well online, provided they can be supported by credible evidence.

Core workflow:
`discover → learn → practice → assess → diagnose → remediate → build → prove → master → advance`

The application is intended to keep the learning workflow inside one environment through native lessons, interactive textbook/readers, diagrams, graphs, simulations, questions, projects, assessments, coding labs, technical workbenches, progress tracking, and contextual AI assistance.

Third-party content is not blindly copied. Built-in learning may use original content, licensed/permissioned content, and provider-approved embeds/APIs. External resources that cannot legally/technically be internalized remain references.

Assessments are mastery gates. Completing a lesson does not automatically unlock the next stage. The evidence can be conceptual answers, novel problems, coding tasks, debugging, design, projects, proofs, or transfer tasks depending on the subject.

AI is a control layer everywhere rather than merely a chat page. It supports lessons, code, assessments, projects, diagrams, notes, search, and progress views. Highlighting supported text/code/concepts can open contextual actions. Meaningful help should often be followed by a transfer challenge.

Gemini may be an initial provider, but the architecture remains provider-neutral. V1 is local-first with no required backend, hosted database, authentication, multi-tenancy, or cloud sync. Progress/settings and relevant learner state persist locally.

Gamification and productivity reinforce demonstrated learning rather than passive clicking. The system tracks route progress, mastery evidence, weak areas, review needs, projects, focus sessions, milestones, and useful consistency metrics.

The project remains documentation-first until these contracts are reviewed and accepted.
