# MasteryOS Source Coverage Crosswalk

## Why this exists

The four supplied sources are complementary, not interchangeable. This crosswalk turns them into one stronger curriculum.

| Source | What MasteryOS takes | What MasteryOS adds |
|---|---|---|
| Class Central | Huge catalog breadth, topic discovery, alternatives, course metadata | competency graph, deduplication, native lessons, mastery gates, diagnostics |
| OSSU | undergraduate CS spine, prerequisite ordering, math/systems/theory/security/applications breadth | deeper software engineering, AI/ML, quant, richer math, local-first execution, contextual AI |
| ForrestKnight | compact university-course map and alternative sequence | cross-checking, stronger prerequisites, deliberate practice, interactive labs, advanced/specialist routes |
| Scrimba | bite-sized interactive learning, browser coding, immediate challenges, projects | same pedagogy across CS/math/systems, mastery evidence, diagnostic remediation, AI coaching |

### Project methodology

- small build;
- guided build;
- independent build;
- integration project;

This preserves the source ecosystem's project orientation while avoiding portfolio-project-only progression.
