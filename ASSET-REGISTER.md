# MasteryOS Asset Register

Every external asset that is actually shipped by MasteryOS must be recorded here.

| ID | Local path | Type | Source URL | Creator | License/terms | Date checked | Reuse class | Attribution | Notes |
|---|---|---|---|---|---|---|---|---|---|

## Reuse classes

- `project-owned`
- `licensed`
- `open-license`
- `reference-only`
- `needs-permission`
- `reject`

## Rules

1. Screenshots used to analyze a reference do not automatically become shippable assets.
2. Verify the individual asset's terms, not only the source site's homepage.
3. Record the exact source and relevant license/terms URL.
4. Keep proof of rights where practical.
5. Never commit credentials, private learner data, or unrelated personal files.
6. Remove or replace assets if their reuse rights become unclear.
7. External educational content can remain a link/reference without becoming a shipped asset.
